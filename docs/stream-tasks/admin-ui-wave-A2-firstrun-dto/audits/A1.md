## Residuals

- **Refactor screens onto `api.generated.ts`** (deferred to
  wave-A3) — Swashbuckle's default emitter marks every
  property as optional (`?:`), which would cascade `T |
  undefined` handling into 30+ screen files. The drift +
  parity GATES catch every backend change regardless;
  switching the screen-side source requires NRT-aware
  required-field inference on Swashbuckle (a small
  swagger gen filter). Wave-A3 is the natural home.
- **Backgrounds still warn in `appsettings.Test.json`** —
  .NET IConfiguration array binding merges by index, so
  `EnabledTasks: []` does NOT clear the inherited
  populated list. Backgrounds run + warn but don't crash
  the host. Fix path documented in the S2 audit prompt
  (DisableAll: bool OR DisabledTasks listing every name).
- **S2 codex audit pending** — prompt drafted at
  `audits/S2-slice-audit-prompt.md`; runs externally after
  this closeout commit. Any findings get folded in an
  `audits/S2-slice-audit-followup.md`.
- **Write-side parity coverage** — Force-rebroadcast (POST
  /api/tx/broadcast) NOT exercised by the contract suite.
  Belongs in wave-A4 (reliability + data safety).

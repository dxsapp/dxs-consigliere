# tx-lab — A1 audit

First audit cycle. Branch `codex/consigliere-vnext`. Range `6d03bf0..1ffe0e2`.

## What landed (S1 `1ffe0e2`, frontend only)
A `/lab` admin screen: generate a P2PKH key in the browser → address
auto-tracked (forward_only) → fund externally → build+sign a simple P2PKH send
client-side with `dxs-bsv-token-sdk` → broadcast via the existing
`POST /api/tx/broadcast` over the node's own P2P pool → receipt. UTXOs from
`GET /api/address/{address}/utxos`. The private key never leaves the browser
(only address + signed rawHex cross the wire). SDK lazy-loaded into its own
chunk; no backend change.

## Validated

- Store unit test asserts: generate derives a stable address + auto-tracks with

## Residuals
- **Live mainnet send unverified** (real funds, real broadcast + confirm) —
  operator-run, evidence-pending. This is the actual demo-video step.
- **v1 = simple P2PKH only** (no tokens, no multi-output/data, no manual UTXO) —
  intentional scope.
- **Keys are demo-grade** (browser memory/session, not custodial) — by design;
  the banner says so. Not for real custody.
- Bundle budget is at 97.8% of cap — headroom is thin; future shell additions
  should watch it.

  `image: dxs/consigliere:${CONSIGLIERE_TAG:-latest}` (pull, not

  `RavenDb__Urls__0=http://ravendb:8080`,

### S3 — NRT sweep → generated re-exports (`bf68fe2`)
- ~18 response DTOs `#nullable enable`d with per-property
  nullability; `types/{admin,auth}.ts` collapsed to
  `export type X = components["schemas"]["X"]`.

  REST schema — documented exception).

## Residuals

- **No published `dxs/consigliere:latest` image yet** — the
  release workflow fires only on a `vX.Y.Z` tag and none has
  been cut. The literal "pull our image" step is gated on a
  maintainer cutting a first release; S1 was validated against a
  locally-built+tagged image. Operator/maintainer action, not a
  code defect. (Tracked in `evidence/S2-ga-checklist.md`.)
- **S2 real-infra run is operator-pending** — real VM + real
  domain → Let's Encrypt cert chain, broadcast-to-real-peers,
  ≥24h soak, and the <45-min runbook stopwatch all need
  infrastructure the engineering loop does not have. The harness
  (soak-watch.sh) + checklist are shipped; the live evidence is
  honestly marked pending per Core Rule 5.
- **Real mainnet index of a watched address** — the
  wizard→config→live-recycle path is code-traced and the front
  door is proven, but indexing a real watched address on mainnet
  with a real JungleBus sub is operator-run evidence-pending.
- **S3 was delegated + recovered** — the sweep agent's terminal
  report was lost to a transient 500 before it committed; the
  operator integrated the landed work and fixed two cascades it
  missed (`p2p.store` `lastSeen` type; the AJV `nullable+allOf`
  validator). All four gates re-run green. Provenance noted; the
  contract is unaffected.
